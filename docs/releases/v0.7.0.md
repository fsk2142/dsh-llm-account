# v0.7.0

补齐 Command Code 全部五个档位的逐模型额度数据，并加上防回归的结构性检查。

## 新增

- **Go / Pro / Max 三档的逐模型额度表**：之前只有 GOAT 档有完整数据，其余档位只有
  pricing 页那 7 个开源模型，用户一切换档位就是大片「未知」。现在从官方
  `docs/plans/{go,pro,max}` 补齐（Go 50 个 / Pro 78 个 / Max 10× 97 个 / Max 20× 97 个）。
- **结构性回归测试**（6 条）：额度表必须是可用清单的子集、免费模型不能被覆盖、
  各档规模锁定、同一模型跨档不能串味。

## 修复

- **GOAT 表改为合并而非覆盖**：v0.4.0 引入的回归——整桶覆盖把 pricing 页标为 `Free`
  的三个模型（Beam 1.0 / Glyph Cluster / Laguna S 2.1）冲掉了，界面上从「免费」变成空白。
- **查不到额度时显示「未知」**：之前是整格不渲染，看起来像功能没生效。

## 数据说明

所有额度数据来自各家官网（没有 API），抓取日期 2026-10-21：

| 厂商 | 来源页面 |
| --- | --- |
| Command Code | `commandcode.ai/docs/plans/{go,goat,pro,max}` |
| Open Design | `open-design.ai/pricing` |
| OpenCode | `opencode.ai/go` |

仍有 8 个模型显示「未知」（GLM-5、Kimi K2.5 等）：官方只公布了它们的 token 单价，
没有 monthly credits，按「不猜」的纪律保持空白。
