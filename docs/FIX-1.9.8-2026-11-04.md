# 1.9.8 修复记录 · 2026-11-04

用户症状：所有模型在运行前失败，显示 `Cannot read properties of undefined (reading 'kind')`。

核对本机内置 DSH 0.2.1-rc.5 的实际代码后，确认 `agent/pre-step` 是 waterfall，监听器必须调用下一层并返回决策。插件新增监听只缓存 agent 后返回 undefined，导致宿主读取 `decision.kind` 时崩溃，与上游是否连通无关。

另确认自动续写入队的消息缺少持久消息来源/身份，且 content 为字符串；宿主直接保存而不规范化，随后可能在读取 `message.source.kind` 时崩溃。本次修正消息构造，并为旧版本遗留的精确匹配续写输入提供兼容修复。

本次还复查网页登录后的认证刷新、额度凭据及登录取消。测试与最终提交信息见同日输出报告。

回归重点：完整 apply 的 pre-step 必须传递并返回下游决策；自动续写必须是宿主可接受的消息；已有旧续写不能继续阻断会话；认证更新与取消不再使可用账号失联。

未调用真实模型服务扣费验证。构建后的本机安装副本需要重载插件或重启 DSH 才会使用新代码。

验证结果：174个测试文件、1752个测试全部通过（含回环登录）；最终类型检查、构建、git diff --check通过。修复版为1.9.8。本次推送沿现有main历史，包含此前尚未推送的7个提交。
